# 🎸 밴드 합주 시간표

교내 밴드부원들이 **아이디로 로그인 → 팀 고르기 → 가능한 시간 칠하기**만 하면, 팀원들이 겹치는 합주 시간을 바로 찾아주는 웹앱입니다.

- **로그인**: 아이디 + 비밀번호. 가입할 때 이름 · 주 파트 · 밴드부를 정해요. 내 폰에서는 로그인이 유지되고, 같이 쓰는 기기에서는 로그아웃하면 돼요.
- **밴드부(소속)**: 관리자만 추가·수정·삭제할 수 있어요.
- **팀**: 곡별 팀이나 고정 팀. 로그인한 사람 누구나 자기 밴드부 안에서 만들 수 있고, 만든 사람이 첫 멤버가 돼요.
- **가능 시간**: 팀마다 따로 입력해요. **내 시간은 나만** 고칠 수 있어요.
- **게스트**: 가입하지 않은 팀원은 팀 멤버가 '게스트'로 넣어서 대신 입력할 수 있어요. 나중에 그 사람이 가입해서 **"이게 나예요"**를 누르면 게스트 시간이 그대로 내 것이 돼요.
- 팀원이 입력한 시간은 실시간으로 반영돼요. 실시간 연결이 안 되면 15초마다 자동으로 새로고침해요.
- 시간표는 로그인한 사람만 볼 수 있어요.

데이터와 로그인은 [Supabase](https://supabase.com) 무료 플랜에 저장하고, 사이트는 GitHub Pages로 배포합니다.

---

## 처음 한 번만: 배포 설정 (관리자, 약 5분)

### 1. Supabase 프로젝트 만들기

1. <https://supabase.com> 에 GitHub 계정으로 가입하고 **New project**를 누릅니다.
2. 이름은 `band-scheduler`, Region은 **Northeast Asia (Seoul)** 을 고르고, DB 비밀번호는 아무거나 길게 정해서 만듭니다. (이 비밀번호는 앱에 쓰지 않아요.)

### 2. 데이터베이스 만들기

1. 왼쪽 메뉴 **SQL Editor** → **New query**
2. 이 저장소의 [`supabase/schema.sql`](supabase/schema.sql) 내용을 **전부** 복사해 붙여넣고 **Run**을 누릅니다.
3. 새 쿼리 창에서 관리자 코드를 정합니다. 따옴표 안을 원하는 코드로 바꿔서 실행하세요.

   ```sql
   select public.set_admin_code('여기에-관리자-코드');
   ```

   관리자 코드를 잊어버리면 이 줄을 새 코드로 다시 실행하면 돼요.

### 3. 로그인 설정: "Confirm email" 끄기

아이디로 가입하는 방식이라 실제 이메일 확인을 할 수 없어요. 꺼야 가입하자마자 로그인돼요.

1. 왼쪽 메뉴 **Authentication** → **Sign In / Providers** (예전 화면에서는 **Providers** → **Email**)
2. **Confirm email**을 끄고 저장합니다.

> 같은 학교 와이파이에서 한꺼번에 많이 가입하면 Supabase의 가입/로그인 횟수 제한에 걸릴 수 있어요. 그럴 땐 **Authentication → Rate Limits**에서 가입·로그인 한도를 올려주세요.

### 4. 앱에 Supabase 주소와 공개 키 넣기

1. Supabase 대시보드에서 **Project Settings → API Keys** (또는 **Data API**)로 갑니다.
2. **Project URL**과 **Publishable key**(`sb_publishable_...`)를 복사합니다.
   예전에 만든 프로젝트라면 `anon` `public` 키(`eyJ...`)를 써도 돼요.
3. 저장소의 [`config.js`](config.js)를 열어 두 값을 넣고 `main` 브랜치에 커밋합니다.

   ```js
   window.BAND_SCHEDULER_CONFIG = {
     supabaseUrl: 'https://abcdefghijklmn.supabase.co',
     supabaseKey: 'sb_publishable_xxxxxxxx',
     loginEmailDomain: 'iseoggyu350-cpu.github.io'
   };
   ```

   `loginEmailDomain`은 아이디를 Supabase가 요구하는 이메일 형식(`아이디@도메인`)으로 바꿀 때만 써요. 실제로 메일을 보내지는 않아요. **한 번 정하면 바꾸지 마세요.** 바꾸면 기존 계정으로 로그인할 수 없어요.

> ⚠️ **secret 키나 `service_role` 키는 절대 넣지 마세요.** 공개(publishable/anon) 키는 원래 웹사이트에 들어가도 되는 키이고, 실제로 무엇을 할 수 있는지는 `schema.sql`의 보안 규칙이 막아줍니다.

### 5. 사이트 확인 & 밴드부 등록

1. GitHub Pages 주소(`https://iseoggyu350-cpu.github.io/band-scheduler/`)로 들어갑니다.
2. 첫 화면 아래의 **관리자**를 눌러 관리자 코드를 입력하고, **밴드부(소속)**를 추가합니다. 순서(▲▼)와 이름도 여기서 바꿀 수 있어요.
3. 관리자도 학생처럼 **회원가입**해서 쓰면 돼요. 관리자 코드는 계정과 따로예요.

### 6. 단톡방에 공유

- **사이트 주소**를 보내면 → 회원가입(처음 한 번) → 내 밴드부 팀 목록 → 팀 고르기.
- 팀 화면의 **이 팀 링크 복사**로 만든 링크를 보내면 → 로그인하자마자 그 팀으로 바로 와요.
- **결과 복사**로 복사한 추천 시간 요약 맨 아래에도 팀 링크가 붙어 있어요.
- 주소창에는 항상 첫 페이지 주소만 보여요. 주소창을 복사해 보내도 받은 사람은 처음부터 시작해요.

## 관리자 화면에서 할 수 있는 것

- **밴드부**: 추가 · 이름 변경 · 순서 변경 · 삭제 (삭제하면 안의 팀과 시간도 함께 지워져요)
- **계정**: 가입한 사람 목록, **비밀번호 초기화**(잊어버린 학생용, 새 비밀번호를 정해서 본인에게 알려주세요), 계정 삭제(그 사람이 있던 팀에는 시간이 그대로 남고 게스트가 돼요)
- **팀**: 아무도 관리하지 않는 팀 삭제
- **관리자 코드 바꾸기**

## 학생이 할 수 있는 것

- **내 정보**(배너나 팀 목록 오른쪽 위 이름): 이름 · 주 파트 · 밴드부 바꾸기, 비밀번호 바꾸기, 로그아웃. 이름을 바꾸면 내가 들어가 있는 모든 팀에서 같이 바뀌어요.
- **팀 참여**: 새로 참여하기, 또는 예전에 들어가 있던 게스트 이름을 골라 **"이게 나예요"**로 이어받기
- **팀 관리**(팀 멤버만): 팀 이름 · 색상 · 합주 기간 바꾸기, 게스트 추가 · 수정, 팀 삭제
- **팀 나가기**: 팀 멤버 목록에서 내 이름 옆 ✕

## 예전 버전을 쓰던 경우

- **v1(로그인 없는 버전)에서 올라올 때**: `supabase/schema.sql`을 한 번 더 실행하세요. 기존 팀과 시간은 그대로 남고, 기존 멤버는 모두 **게스트**가 돼요. 각자 가입해서 팀에 들어갈 때 자기 이름을 골라 "이게 나예요"를 누르면 이어져요.
- **GitHub 동기화 버전의 예전 초대 링크(`#gh=...`)**: 들어오면 링크 속 토큰은 바로 지워지고 로그인 화면으로 안내돼요. 예전 GitHub 토큰은 폐기하는 걸 추천해요.
  (GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → 해당 토큰 → Delete)

## 알아두면 좋은 것

- **보안 규칙은 서버(Supabase)가 지켜요.** 화면을 고치거나 API를 직접 불러도 남의 시간을 바꾸거나 남의 팀을 지울 수 없어요.
- **비밀번호**는 Supabase가 암호화해서 저장해요. 관리자도 비밀번호를 볼 수는 없고, 초기화만 할 수 있어요.
- **Supabase 무료 플랜**은 한동안(현재 기준 약 1주일) 아무도 접속하지 않으면 프로젝트가 일시정지될 수 있어요. 오래 안 쓰다가 다시 쓸 때 사이트가 안 열리면 Supabase 대시보드에서 프로젝트를 **Restore**하면 돼요. 데이터는 그대로 있어요.
- `schema.sql`은 여러 번 실행해도 기존 데이터를 지우지 않아요. 앱이 업데이트되면서 스키마가 바뀌면 다시 실행하면 돼요.

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 구조 |
| `app.js` | 앱 동작 (로그인, 팀 고르기·참여, 시간표, 추천, 동기화, 관리자) |
| `config.js` | Supabase 주소 · 공개 키 · 로그인 도메인 (관리자가 수정) |
| `supabase/schema.sql` | 데이터베이스 테이블 · 보안 규칙 · 관리자 기능 |
