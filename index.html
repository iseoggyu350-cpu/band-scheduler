GitHub 전용 실시간 동기화 (무료)

다른 서비스 가입 없이 GitHub 저장소의 data 브랜치에 시간표를 자동 저장합니다. 본인만 여기서 한 번 연결한 뒤 친구 초대 링크 복사를 카톡에 보내면, 친구는 아무 설정 없이 바로 입력하고 서로 실시간으로 볼 수 있습니다.

상태: 미연동
🔒 안전 안내

친구 초대 링크에는 이 저장소 전용 토큰이 포함됩니다. 신뢰하는 밴드 친구들 단톡방에만 공유해 주세요. (토큰 권한을 이 저장소 1개로만 제한하면 다른 저장소에는 전혀 접근할 수 없습니다.)

  1. GitHub 로그인 후 Fine-grained Token 발급 페이지로 이동합니다.
  2. Token name: band-scheduler 입력 / Expiration: 원하는 기간(예: 1년) 선택.
  3. Repository access에서 Only select repositories 선택 → band-scheduler 저장소 1개만 체크.
  4. 아래 Permissions > Repository permissions에서 Contents 항목을 Read and write로 변경.
  5. 맨 아래 Generate token 클릭 → 생성된 github_pat_... 토큰을 복사해서 1번 탭에 붙여넣고 연결하고 불러오기 클릭!
  6. 연결되면 친구 초대 링크 복사 버튼을 눌러 친구에게 보내세요. 친구는 링크만 누르면 끝입니다!

시간표 코드 공유 / 불러오기

동기화 연결 없이도 현재 시간표 데이터를 코드로 복사해 친구들에게 보내거나, 친구가 보낸 코드를 붙여넣어 덮어쓰기 또는 병합할 수 있습니다.
